# Support

If you need help:

- Review `INSTRUCTIONS.md` for setup steps
- Check `helpers/snowflake/spcs-setup.sh` for interactive diagnostics
- Use `helpers/snowflake/troubleshoot.py` for deeper analysis
- Verify GitHub secrets and Snowflake roles
- Examine service logs using `SYSTEM$GET_SERVICE_LOGS`

For feature requests or bugs, open an issue in the repository with logs and reproduction steps.
